# BibBot

BibBot is a simple Discord bot built with Python and Discord.py. It was created as an early personal project to learn how Discord bots work, how APIs can be integrated into a project, and how to manage code with GitHub.

## Features

- Responds to basic Discord bot commands
- Connects to an AI API for chatbot-style responses
- Uses environment variables to store sensitive information securely
- Built as a beginner-friendly learning project in Python

## Tech Stack

- Python
- discord.py
- AI API integration
- Git and GitHub

## Purpose

This project was made as a first step into software development and AI-related projects. The goal was to learn how to:
- build and run a Discord bot,
- connect a bot to an external API,
- debug common setup issues,
- and upload/manage a project on GitHub.

## Project Status

This is an early learning project and may continue to improve over time as new features and cleaner code are added.

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/josh-gedeon/discord-bot.git
   ```

2. Move into the project folder:
   ```bash
   cd discord-bot
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Create a `.env` file and add your keys:
   ```env
   DISCORD_TOKEN=your_discord_token_here
   AI_API_KEY=your_api_key_here
   ```

5. Run the bot:
   ```bash
   python BibBot.py
   ```
